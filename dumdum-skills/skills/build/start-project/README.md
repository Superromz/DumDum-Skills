# Start Project

**Command:** `/dumdum:start-project`

## What it does

Sets up a brand new project from scratch and gets something running on your screen. You describe what you want to build in plain English, and it creates all the files, installs what is needed, and walks you through every piece so nothing feels like a mystery.

## When to use it

You have an idea for something you want to build but no code yet. This is your starting point.

## Example conversation

> **You:** /dumdum:start-project
>
> **Claude:** What do you want to build? Describe it like you are explaining it to a friend.
>
> **You:** I want a simple website where people can submit their favorite book recommendations.
>
> **Claude:** Got it. I will set up a web project with a form for submitting books and a page that shows all the recommendations. Let me create the files and explain each one as I go.

## What you get at the end

A working project with all files created, dependencies installed, and a plain-English explanation of what every file does and how the pieces fit together.

## Suggested next skills

- `/dumdum:add-feature` to build on top of what you just created
- `/dumdum:make-it-look-good` to improve the visual design
