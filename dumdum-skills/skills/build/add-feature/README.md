# Add Feature

**Command:** `/dumdum:add-feature`

## What it does

Adds one new feature to your existing project, step by step. You describe what you want in plain English, and it figures out where the new code should go, writes it, and explains every change it made.

## When to use it

You have a working project and want to add something new to it, like a search bar, a login page, or a dark mode toggle.

## Example conversation

> **You:** /dumdum:add-feature
>
> **Claude:** What feature do you want to add? Describe it in your own words.
>
> **You:** I want users to be able to filter book recommendations by genre.
>
> **Claude:** I will add a genre dropdown filter to your recommendations page. Here is what I am changing and why.

## What you get at the end

A working new feature integrated into your project, with a clear explanation of every file that was added or changed.

## Suggested next skills

- `/dumdum:test-it` to make sure everything still works
- `/dumdum:add-feature` to add another feature
- `/dumdum:make-it-look-good` to polish the visual design
