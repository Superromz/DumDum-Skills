# Teach Me

**Command:** `/dumdum:teach-me`

## What it does

Teaches you any concept from your project using simple analogies and real examples. It starts with the big picture, then adds detail layer by layer, and finishes by showing you exactly where the concept appears in your own code.

## When to use it

You see something in your project you do not understand, or you want to learn how a piece of your project works under the hood.

## Example conversation

> **You:** /dumdum:teach-me
>
> **Claude:** What do you want to learn about? Pick something from your project, or ask about any concept you have seen.
>
> **You:** What is an API?
>
> **Claude:** Think of an API like a restaurant menu. You do not go into the kitchen yourself. You read the menu, place an order, and get food back. Your project uses an API right here in this file to get weather data the same way.

## What you get at the end

A layered explanation starting with a simple analogy, then adding detail, then showing where it appears in your project.

## Suggested next skills

- `/dumdum:glossary` to get definitions for all the technical terms in your project
- `/dumdum:explain-it` to get a walkthrough of a specific piece of code
