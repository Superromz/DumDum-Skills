# Glossary

**Command:** `/dumdum:glossary`

## What it does

Scans your project and builds a jargon-free dictionary of every technical term it finds. Each entry gets a plain English definition and a simple analogy so you can understand it without prior programming knowledge.

## When to use it

You keep running into words or concepts you do not recognize, and you want a single reference you can check anytime.

## Example conversation

> **You:** /dumdum:glossary
>
> **Claude:** I scanned your project and found 12 technical terms. Here is your glossary. Want me to save it as a file in your project?
>
> **You:** Yes, save it.
>
> **Claude:** Done. I saved it as GLOSSARY.md in your project folder. You can open it anytime to look up a term.

## What you get at the end

An alphabetical glossary with plain-English definitions and analogies.

## Suggested next skills

- `/dumdum:teach-me` to dive deeper into any concept from the glossary
- `/dumdum:explain-it` to get a walkthrough of a specific piece of code
