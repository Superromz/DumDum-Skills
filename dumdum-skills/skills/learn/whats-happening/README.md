# What's Happening

**Command:** `/dumdum:whats-happening`

## What it does

Gives you a plain English summary of your project's current state. It tells you what is built, what is in progress, and what is broken, without using jargon or assuming you remember where you left off.

## When to use it

You are coming back to a project after a break, or you just want a clear picture of where things stand right now.

## Example conversation

> **You:** /dumdum:whats-happening
>
> **Claude:** Here is where your project stands. The homepage and about page are done. The contact form is half-built. There is one error in the login page that will need fixing.
>
> **You:** What is the error?
>
> **Claude:** The login form tries to send data to a server that does not exist yet. You will need to set that up or use a placeholder.

## What you get at the end

A status report covering what is built, what is in progress, and what is broken.

## Suggested next skills

- `/dumdum:whats-left` to see remaining work as a checklist
- `/dumdum:add-feature` to keep building
- `/dumdum:fix-problem` to address anything that is broken
