# Explain It

**Command:** `/dumdum:explain-it`

## What it does

Takes any file in your project and explains what it does in plain English, section by section. No jargon, no assumptions about what you already know. If a technical term comes up, it gets explained right there in the same sentence.

## When to use it

You are looking at a file and want to understand what it does, how it works, or why it was written that way. Maybe you inherited code from someone else, or you want to revisit something you built a while ago.

## Example conversation

> **You:** /dumdum:explain-it
>
> **Claude:** Which file do you want me to explain?
>
> **You:** The main server file, server.js.
>
> **Claude:** Here is what server.js does, broken into sections. The first part sets up the web server. The second part defines what happens when someone visits each page. The third part starts listening for visitors on port 3000.

## What you get at the end

A section-by-section explanation of the file in everyday language, covering what each part does and how the pieces connect.

## Suggested next skills

- `/dumdum:teach-me` to go deeper and learn the concepts behind the code
- `/dumdum:review-it` to check the whole project for issues
