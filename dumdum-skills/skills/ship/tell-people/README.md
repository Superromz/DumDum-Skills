# Tell People

**Command:** `/dumdum:tell-people`

## What it does

Generates a README, a short project description, and a social media post so you can share your project with others. Everything is written in plain language based on what your project actually does.

## When to use it

Your project is ready to show off and you want to tell people about it, whether on GitHub, social media, or anywhere else.

## Example conversation

> **You:** /dumdum:tell-people
>
> **Claude:** I looked at your project. Here is a draft README, a one-sentence description, and a social media post. Want me to adjust the tone or add anything?
>
> **You:** Can you make the social post more casual?
>
> **Claude:** Sure, here is a more casual version. I also saved the README to your project.

## What you get at the end

A README file, a short project description, and a social media post.

## Suggested next skills

- `/dumdum:put-it-online` to publish your project so the links work
- `/dumdum:save-progress` to save a checkpoint with your new README
