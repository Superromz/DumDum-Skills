# Clean Up

**Command:** `/dumdum:clean-up`

## What it does

Finds unused code and disorganized files in your project, then removes or reorganizes them. It explains every change it makes so you understand what was cleaned up and why.

## When to use it

Your project feels messy, you have files you are not sure about, or you want to tidy things up before adding something new.

## Example conversation

> **You:** /dumdum:clean-up
>
> **Claude:** I found three unused files and two chunks of code that are not doing anything. Here is what I recommend removing. Want me to go ahead?
>
> **You:** Yes, clean it up.
>
> **Claude:** Done. I removed the unused files and dead code. Here is a summary of everything I changed.

## What you get at the end

A cleaner project with a summary of everything that was removed or reorganized.

## Suggested next skills

- `/dumdum:save-progress` to save a checkpoint after cleaning up
- `/dumdum:test-it` to make sure everything still works
