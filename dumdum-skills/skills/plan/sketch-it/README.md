# Sketch It

**Command:** `/dumdum:sketch-it`

## What It Does

This skill helps you describe what each screen or page of your project looks like, using plain language. Claude turns your descriptions into simple text-based sketches showing where things go on the screen, then connects all the screens into a map so you can see how people will move through your project.

## When to Use It

Use this when you want to plan what your project will look like before building it. You do not need any design experience. Just describe what you imagine, and Claude will sketch it out for you.

## Example Conversation

> **You:** The first page should have a big search bar and some popular listings below it.
>
> **Claude:** Here is a sketch of that. (Shows a simple text layout with a header, search bar in the center, and a row of listing cards below.) Does this feel right, or do you want to move things around?
>
> **You:** Can we add a "Sign In" button in the top right corner?
>
> **Claude:** Done. Now, when someone clicks on one of those listings, what should they see next?
>
> **You:** A page with more details about that listing, like photos and a description.

## What You Get at the End

- **ASCII sketches** of each screen, showing the layout and structure in plain text
- A **screen map** that shows every screen and how they connect to each other, so you can see the full flow of your project at a glance
